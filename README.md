# Каталог идей для Python-проектов

Программа хранит список идей для будущих Python-проектов, выводит их на экран
и позволяет добавлять новые идеи через консоль.

## Как запустить

1. Убедитесь, что установлен Python 3.x
2. Откройте папку `project_ideas`
3. Запустите программу командой: `python main.py`
4. Следуйте подсказкам на экране.
